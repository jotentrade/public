# 小小腦力探險 — PWA / RWD 版

純前端幼兒圖形認知遊戲式篩查原型，可自行部署與修改。

## PWA 功能
- 可安裝到手機／平板／桌面
- Service Worker 離線快取
- Standalone App 顯示模式
- 原創 SVG App 圖示
- 不依賴第三方 CDN

## RWD
- 手機、平板、桌機自適應
- 小螢幕與橫向畫面最佳化
- 大螢幕四欄選項
- iPhone / iPad safe-area 支援

## GitHub Pages
本專案部署於 `/kids-cognitive-test/` 子路徑，所有 PWA 資源均使用相對路徑。
